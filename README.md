# Zoom Deck

Zoom を Stream Deck のように操作する、Mac 用のツールです。Zoom に映す映像と音を OBS で作り、画面のボタンとキーボードのショートカットで切り替えます。

個人が作ったツールで、Zoom や Elgato（Stream Deck）の公式のものではありません。

## できること

- **音楽をきれいに流す**：キーボードの音や雑音を消した声と、パソコンの音楽（YouTube、Spotify など）を混ぜて Zoom に送ります。相手の画面共有中でも流せます。
- **アバターで参加する**：VRM のアバターが、カメラの顔の動きに合わせて動きます。
- **実写のまま背景を変える**：人物を切り抜いて、好きな画像や動画の上に重ねます。
- **離席の画面と CM**：ボタン 1 つでマイクを切り、離席のアニメーションや自分の動画を流します。
- **効果音のボタン**：自分で入れた効果音を Zoom に流します。
- **YouTube の操作**：再生中の曲名の確認、一時停止、次の曲への移動ができます（Chrome の拡張機能を使います）。
- **全体ショートカット**：Zoom を操作中でも ⌃⌥M でマイクを切り替えられます。

## 必要なもの

- Mac（動作を確かめたのは Apple シリコン、macOS 26 です。Intel の Mac では試していません）
- [Homebrew](https://brew.sh)
- Zoom のアプリ
- 空き容量 約 2GB とネットの接続（アバターの部品などは使うときにネットから読み込みます）

## セットアップ

1. ターミナルで次を実行します。足りない物（Node、ffmpeg、OBS、BlackHole 2ch、アバター用のブラウザ）を入れて、アプリ「Zoom Deck」を作ります。途中で Mac のパスワードを聞かれることがあります。

   ```bash
   git clone https://github.com/inose-yuudai/zoom-deck.git
   cd zoom-deck
   ./setup.command
   ```

2. `/アプリケーション` の「Zoom Deck」を開きます。OBS、アバターの画面、ボタン盤が順に開きます。

   初回だけ、次の確認が出ます。

   | 出てくるもの | すること |
   |---|---|
   | OBS の「自動構成ウィザード」 | 「キャンセル」を押す |
   | OBS のマイク・画面収録の許可 | 許可する |
   | アバターの画面のカメラの許可 | 許可する |
   | 仮想カメラの確認 | システム設定 → 一般 → ログイン項目と機能拡張 → カメラ機能拡張 で OBS をオンにする |

   許可したあとでうまく動かないときは、OBS を閉じて「Zoom Deck」を開き直してください。

3. Zoom の設定を変えます。

   | 項目 | 設定 |
   |---|---|
   | マイク | BlackHole 2ch |
   | スピーカー | いつものヘッドホンやスピーカー（BlackHole にしない） |
   | カメラ | OBS Virtual Camera（一覧に無いときは Zoom を ⌘Q で終了して開き直す） |
   | オーディオの詳細 | 「ミュージシャン用のオリジナル サウンド」をオン |
   | 背景 | なし（背景は Zoom Deck で選びます） |

## YouTube の拡張機能（使うときだけ）

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」を押し、次のフォルダを選びます。

   `~/Library/Application Support/AvatarCam/youtube-extension`

3. YouTube のタブを開き直して再生すると、ボタン盤に曲名が出ます。

## 自分の素材の入れ方

最初はサンプルのアバターが 1 体だけ入っています。素材は自分で入れてください。

| 入れるもの | 入れ方 |
|---|---|
| アバター（.vrm） | `~/Library/Application Support/AvatarCam/app/models` に入れて、ボタン盤を開き直す |
| 背景（画像・動画） | ボタン盤の「背景」の「＋ 画像・動画」 |
| 効果音 | ボタン盤の「効果音」の「編集」→「＋ フォルダ」でフォルダを作り、「＋ 効果音」で追加 |
| 離席の CM（動画） | ボタン盤の「CM・動画ライブラリ」 |

音楽、動画、モデルの権利は、使う人がそれぞれ確かめてください。

## 使うとき

- 始めるとき：アプリ「Zoom Deck」を開きます。調子がおかしいときも、まずこれをもう一度押してください。足りない物だけ起動し直します。
- 終わるとき：ボタン盤の一番下の「すべて終了」を押します。
- ショートカットの一覧はボタン盤の一番下にあります。

OBS を配信など別の用途で開いているときは、Zoom Deck は OBS に触りません。アプリを押すと、Zoom 用に切り替えてよいかを聞きます。

## うまくいかないとき

| 困っていること | 確かめること |
|---|---|
| Zoom に声が届かない | ボタン盤のマイクが「ON AIR」か。Zoom 側でミュートしていないか。OBS が Zoom 用の設定か |
| 音楽が届かない | 音を拾えるのは ミュージック、Chrome、Safari、Spotify です。ボタン盤の「音楽アプリを再接続」を押してください |
| 声や音楽が小さい | 「Audio MIDI 設定」で BlackHole 2ch の音量が最大か |
| Zoom のカメラに OBS が出ない | Zoom を ⌘Q で終了して開き直す。それでも出なければ Mac を再起動する |
| アバターが固まる | アバターの画面を最小化していないか（他の窓の裏に隠れるのは大丈夫です） |

起動の記録は `~/Library/Logs/ZoomDeck.log` にあります。

## 更新

`zoom-deck` のフォルダで `git pull` してから、もう一度 `./setup.command` を実行します。入れたモデル、背景、効果音、動画は消えません。

## アンインストール

ボタン盤の「すべて終了」を押してから、次を消します。OBS、BlackHole 2ch、Node、ffmpeg は別のアプリなので、要らなければ Homebrew で消してください。

- `/Applications/Zoom Deck.app`
- `~/Library/Application Support/AvatarCam`（入れた素材もここにあります）
- `~/Library/Logs/ZoomDeck.log`
- Chrome の拡張機能「Zoom Deck × YouTube」
- OBS のプロファイル「Zoom」とシーンコレクション「Zoom（音楽+アバター）」

## 安全について

- ボタン盤のサーバーは、この Mac の中（127.0.0.1）でだけ動きます。別のサイトからの操作は断ります。
- カメラの映像、声、素材を外へ送ることはありません。Zoom に送られるのは、使う人が Zoom で選んだ映像と音だけです。
- ネットにつなぐのは、主にアバターの表示に使う部品（three.js、MediaPipe など）を読み込むときと、セットアップのときです。

## Live2D について

この配布版では Live2D を外してあります。利用者が好きな Live2D モデルを読み込めるアプリには、Live2D 社の事前の承認が要る可能性があるためです。
